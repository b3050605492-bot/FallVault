# FallVault 浏览器扩展 🧩

让浏览器跟 FallVault 桌面端联动：**自动填充账号密码 + 一键保存新注册的账号**。

## 工作原理

```
浏览器扩展 ──(本地 127.0.0.1:6666 HTTP)──► FallVault 桌面端
    │                                          │
    └─ 读取/写入账号                          └─ SQLite 本地密码库
```

- 全部数据留在本机，不过任何服务器
- 扩展通过**配对码**与桌面端建立信任连接
- 桌面端未运行时，扩展不会请求任何数据

## 安装方法

### 方式一：加载已解压的扩展（推荐，最简单）

1. 下载并解压本目录（或 zip 包）到本地文件夹
2. 打开 Edge/Chrome → 地址栏输入：
   - **Edge**：`edge://extensions`
   - **Chrome**：`chrome://extensions`
3. 打开右上角 **「开发人员模式」** 开关
4. 点 **「加载解压缩的扩展」** → 选中解压后的 `extension` 文件夹
5. 成功加载，工具栏出现 🔑 图标

### 方式二：安装 .crx（Chrome 系）

> ⚠️ Chrome 新版本禁止直接拖拽 crx 安装（需要企业策略），**推荐用方式一**。
> 方式一 10 秒搞定，效果完全一样。

### 方式三：上架商店（后续可做）

需要 Chrome Web Store 开发者账号（一次性 $5），上架后按钮一键安装。
打算等离线版测试稳定后再考虑。

## 首次配对（1 分钟）

1. 启动 **FallVault 桌面端**
2. 打开 设置 → **浏览器扩展**
3. 复制显示的**配对码**
4. 点浏览器工具栏的 🔑 图标 → 粘贴配对码 → **配对并连接**
5. 看到「已连接 FallVault」绿色圆点 = 配对成功

## 使用

### 🚀 登录页自动填充
- 打开任意有账号的网站登录页（如 GitHub/B站）
- 密码框右侧自动出现 **🔑 小按钮**
- 点它 → 弹出该站点的账号列表 → 选一个 → **自动填入账号密码**

### 💾 注册/新建账号自动保存
- 在注册表单输入用户名+密码并提交时
- 右下角弹出 **「保存此账号到 FallVault？」**
- 可修改标题 → 点保存 → 账号存入本地密码库
- 下次登录同一站点即可直接填充

## 常见问题

| 问题 | 解决 |
|---|---|
| 扩展显示"FallVault 未运行" | 先启动 FallVault 桌面端，再刷新扩展 |
| 配对码错误 | 重新打开 设置→浏览器扩展 复制最新配对码 |
| 某网站没有 🔑 按钮 | 该站登录框是自定义组件（如 iframe），扩展可能会漏掉，可手动在 FallVault 添加 |
| 想断开连接 | 点 🔑 → 断开连接 |

## 打包文件说明（在 dist-extension/）

- `FallVault-extension.crx` — 商店格式包（供高级用户）
- `FallVault-extension.zip` — 解压后用"方式一"加载
- `fallvault-key.pem` — 签名密钥（**务必保管**，更新版本需用它，泄露会导致扩展被冒充）
